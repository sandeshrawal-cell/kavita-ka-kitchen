# Kavita ka Kitchen 3.1

This update adds 153 reviewed licensed dish photos, an interactive cuisine map, swipe discovery, fuller natural-language parsing, recurring menu previews, an on-page calendar dish shelf, pantry deductions, consumption records, household taste views, event and production schedules, private recipe photos, recipe-card downloads, beginner cooking help, optional voice input, static public recipe pages and an optional consent-based AI/vision integration.

Use the included DEPLOYMENT.md to update the existing infrastructure. The site has not been published and the live database is unchanged. Read FEATURE_STATUS.md for the distinction between completed development, provider activation, live verification and outstanding content/features. Full catalogue coverage and all photographs remain unfinished.

The previous 3.0 ZIP is retained separately as the earlier verified release. This ZIP contains source, lockfile, tests, migrations and prebuilt dist output; it excludes local credentials, installed dependencies and private test storage.
